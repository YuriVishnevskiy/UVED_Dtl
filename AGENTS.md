# UVED

Работай с этой Git-копией сайта. `index.html` — точка входа, `app.js` — интерфейс калькулятора, `pricing.js` — тарифы, `visuals.js` и `showroom.js` — визуализация. Three.js поставляется в `vendor/`.

Локальный запуск из корня: `node dev-server.mjs`. Открывай `http://127.0.0.1:8000/#calculator`. Сервер обслуживает страницу и API. Если порт 8000 занят, запусти `PORT=8001 node dev-server.mjs` и открой тот же маршрут на порту 8001. Для учебного прогона запускай сервер без `OPENAI_API_KEY`. Синтаксис изменённых JavaScript-файлов проверяй через `node --check <file>`.

При изменении расчёта сверяй стоимость с `pricing.js` и проверяй оба формата обслуживания в браузере. Для прогона используй `$uved-check`. Перед завершением проверь `git status --short` и `git diff`. Для отправки изменений и публикации нужен отдельный запрос пользователя.
